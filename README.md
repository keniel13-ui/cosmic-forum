# The Cosmic Forum

An archive of history, pattern and record that shows its sources, labels its uncertainty, and keeps interpretation separate from the record.

**Live:** https://keniel13-ui.github.io/cosmic-forum/

## What's inside
- **The Archive:** 68 entries plus 14 pillars on history, power and memory. Claims carry labels: verified, high-confidence, contested, unknown.
- **Essays:** finished pieces, dated and kept as written. Each one says where it first appeared, and corrections are added openly. The first is *Everybody Has an AI Apocalypse Story. Almost Nobody Reads the Fine Print* (first published on [DEV](https://dev.to/kenielzep97/everybody-has-an-ai-apocalypse-story-almost-nobody-reads-the-fine-print-43hm)).
- **The Method and Standards:** how the Forum reads, sources and revises.

## How it's built
One static page, `index.html`, served by GitHub Pages. There's no build step and no tracking. Open the file in a browser to read it locally.

## What's not here
Work in progress isn't published. Drafts live in a separate private workshop until they're finished and approved.
